Interface Numbering Conventions

On a router, interfaces are numbered in the format of slot ID/subcard ID/interface sequence number.

The management interface (marked with the MGMT silkscreen) is numbered MEth0/0/0. Interfaces of different rates are numbered separately. For example, the first GE interface is numbered GE0/0/0, the first 10GE interface is numbered 10GE0/0/0, the first 25GE interface is numbered 25GE0/0/0, the first 40GE interface is numbered 40GE0/0/0, and the first multi-GE interface is numbered MultiGE0/0/0. Subsequent GE interfaces are numbered in ascending order, as are subsequent 10GE, 25GE, 40GE, and multi-GE interfaces.

  • Slot ID

    The slot ID identifies the slot in which a card is installed.

    • The slot ID of an SRU is 0.
    • When slots are combined into one slot, the larger slot ID is used as the new slot ID. For example, when slot 1 and slot 2 are combined, slot ID 2 is used as the new slot ID.
  • Subcard ID

    The subcard ID specifies the ID of a subcard. Since the router does not support subcards, its subcard ID is fixed at 0.

  • Interface sequence number

    The interface sequence number indicates the position of an interface on a card.
