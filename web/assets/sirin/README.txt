SIRIN urban design v005. Newly arranged city using Ragnarok Online artwork. 22 additional model types, grouped market/service/cafe/garden furnishing; original 360m layout and rooms preserved. Full transformed object envelopes (including tree crowns) are checked against disjoint grass/paved terrain; see surface-validation.json and terrain-triangles.json. Exact checks: node scripts/verify-sirin-surfaces.mjs. Navigation: node scripts/verify-sirin-portals.mjs. Runtime has GPU instancing and WebP textures, embedded in a self-contained GLB. Source artwork provenance: ro-provenance.json, life-provenance.json and urban-provenance.json. NPCs remain ambient static scenery.

Night lighting: lighting-layout.json adds 68 catalog fixtures (L047/L107) to the 115 existing lamps. All 183 lamps use fixed world-space illumination and 287 instanced glow emitters, with no camera-distance light selection. ground-navigation.json allows all terrain while retaining solid buildings, towers and structural gate sections; decoration does not block walking. Authoring scripts: build-ground-navigation.py, plan-sirin-lighting.py and plan-ayothaya-lighting.py (Python with NumPy/Shapely). Original navigation.json is retained as source data.
